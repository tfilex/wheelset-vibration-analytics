### ФАЙЛ 1: `src/features/kurtogram.py`

**Что делает:** реализует Fast Kurtogram (Antoni, 2007) — поиск частотной полосы с максимальным спектральным эксцессом для выделения импульсных составляющих от дефектов подшипников.

**Требования:**
- Входной сигнал: `np.ndarray` одного канала (например, ось Z акселерометра)
- Параметры: `fs` (частота дискретизации, Гц), `n_levels` (глубина дерева, по умолчанию 8)
- Выход: объект с полем `best_band = (f_center, bandwidth, kurtosis_value)` и двумерной картой эксцессов
- Метод: банк полосовых FIR-фильтров (`scipy.signal.firwin`), огибающая через преобразование Гильберта (`scipy.signal.hilbert`)
- Формула спектрального эксцесса: `K4 = E[|H(t)|^4] / E[|H(t)|^2]^2 - 2`
- Добавить функцию `plot_kurtogram(kurtogram_result, save_path)` для сохранения рисунка в PNG

**Важно:** функция должна корректно работать на типичных CWRU-сегментах (fs=12000 Гц или 48000 Гц, N=4096 отсчётов).

### ФАЙЛ 2: `src/features/stat_features.py`

**Что делает:** извлекает 5 статистических признаков из временного ряда виброускорения.

**Требования:**
- Функция `extract_stat_features(x: np.ndarray) -> dict`
- Возвращает словарь с ключами: `rms`, `peak_factor`, `kurtosis`, `crest_factor`, `variance`
- Формулы:
  - RMS = sqrt(mean(x²))
  - Peak Factor = max(|x|) / RMS
  - Kurtosis = E[(x-μ)⁴] / σ⁴  (использовать `scipy.stats.kurtosis(fisher=False)`, т.е. Pearson kurtosis; нормальный = 3.0)
  - Crest Factor = max(|x|) / RMS  (то же что Peak Factor — зафиксировать это в docstring)
  - Variance = E[(x-μ)²]
- Функция `batch_extract(segments: np.ndarray) -> pd.DataFrame` для обработки массива сегментов shape `(N, T)`
- Обработка edge case: если RMS == 0, возвращать NaN для признаков с делением на RMS

### ФАЙЛ 3: `src/models/hmm_baseline.py`

**Что делает:** реализует базовую линию на основе скрытых марковских моделей (HMM) для задачи предсказания RUL, чтобы сравнить с нейросетями.

**Требования:**
- Библиотека: `hmmlearn` (GaussianHMM)
- Класс `HMMRULPredictor` с методами:
  - `fit(sequences: List[np.ndarray], lengths: List[int])` — обучение на последовательностях деградации XJTU-SY
  - `predict_rul(sequence: np.ndarray) -> np.ndarray` — предсказание нормированного RUL [0,1] для одной последовательности
  - `evaluate(sequences, true_ruls) -> dict` — возвращает словарь с метриками RMSE, MAE, R²
- Параметры конструктора: `n_components=4`, `covariance_type="full"`, `n_iter=200`, `random_state=42`
- Метод подбора оптимального числа компонент по критерию BIC: `select_n_components(sequences, n_range=(2, 8))`
- Предсказание RUL: нормированный остаток = (T - t) / T, где T — полная длина траектории; для онлайн-предсказания использовать вероятности вхождения в финальное состояние

**Скрипт сравнения:** создать `experiments/run_hmm_comparison.py`, который:
1. Загружает данные XJTU-SY (используй тот же путь/формат, что и нейросети в проекте)
2. Обучает HMM на train-разбивке
3. Вычисляет RMSE, MAE, R² на test-разбивке
4. Логирует результаты в MLflow (run name: `"HMM_baseline_K{n_components}"`)
5. Сохраняет итоговую таблицу сравнения в `results/hmm_vs_nn_comparison.csv`

### ФАЙЛ 5: `src/utils/health_index.py`

**Что делает:** вычисляет Health Index, конвертирует RUL в километры, определяет диагностический статус.

**Требования:**

```python
L_MAX_KM = 1_000_000  # ГОСТ 11018-2011, буксовый подшипник РУ1Ш-957942
```

- `compute_hi(rul_norm_series: np.ndarray, window: int = 10) -> np.ndarray`
  - Сглаживает нормированный RUL скользящим средним
  - Возвращает HI ∈ [0, 1]

- `compute_slope(hi_series: np.ndarray, n: int = 20) -> float`
  - Линейный тренд HI за последние n шагов
  - Отрицательный = деградация, положительный = стабилизация

- `rul_to_km(hi_smooth: float, slope: float = 0.0, alpha: float = 0.2, l_max: float = L_MAX_KM) -> tuple[float, float]`
  - Возвращает `(rul_km, sigma_km)`
  - Формула: `rul_base = hi_smooth * l_max`; `rul_adj = rul_base * (1 + alpha * slope)`; `sigma = abs(slope) * l_max * 0.05`
  - Никогда не возвращать отрицательное значение rul_km

- `get_status(hi: float) -> tuple[int, str, str]`
  - Возвращает `(level, name, color)` где color — строка для Streamlit `st.markdown`
  - Пороги:
    - HI > 0.85 → (1, "Норма", "green")
    - 0.60 < HI ≤ 0.85 → (2, "Удовлетворительно", "orange")
    - 0.35 < HI ≤ 0.60 → (3, "Требует контроля", "red")
    - HI ≤ 0.35 → (4, "АВАРИЙНОЕ", "red")  # + дополнительный флаг emergency=True

- `format_rul_display(rul_km: float, sigma_km: float) -> str`
  - Возвращает строку вида `"~42 000 км ± 5 000 км"` с форматированием тысяч

### ФАЙЛ 6: `src/utils/thresholds.py`

**Что делает:** скоростно-зависимые пороги виброускорения.

- `alert_level(rms_g: float, speed_kmh: float) -> str`
  - "normal" / "warning" (>1.0× порога) / "critical" (>1.5× порога)

import numpy as np
from src.features.kurtogram import fast_kurtogram

def test_kurtogram_healthy():
    """Здоровый сигнал — кайм K4 должен быть низким (близко к 0)."""
    rng = np.random.default_rng(42)
    x = rng.normal(0, 1, 8192)
    _, best = fast_kurtogram(x, fs=12000, n_levels=5)
    level, band_idx, f_center, k4_val = best
    assert k4_val < 5.0  # нет ударных компонент

def test_kurtogram_impulsive():
    """Импульсный сигнал — должны появиться высокие значения K4."""
    rng = np.random.default_rng(42)
    x = rng.normal(0, 0.1, 8192)
    # Добавляем периодические импульсы на частоте 120 Гц при fs=12000
    t = np.arange(8192) / 12000
    impulse_freq = 120
    for i, ti in enumerate(t):
        if abs(ti * impulse_freq - round(ti * impulse_freq)) < 0.001:
            x[i] += rng.exponential(5)
    _, best = fast_kurtogram(x, fs=12000, n_levels=5)
    level, band_idx, f_center, k4_val = best
    assert k4_val > 2.0  # есть ударные компоненты
