## 4. Раздел 2.4. Архитектура решения

После описания выхода RUL-предиктора добавить постобработку прогноза.

Что вставить:

- `HI(t)` вычисляется как сглаженная нормированная оценка RUL;
- сглаживание выполняется скользящим средним;
- локальный наклон `slope` используется как поправка на динамику деградации;
- остаточный пробег переводится в километры по формуле:

```text
RUL_km = HI * L_max * (1 + alpha * slope),
```

где `L_max = 1 000 000 км`, `alpha = 0.2`.

Таблица статусов:

| Диапазон HI | Статус |
|---|---|
| `HI > 0.85` | Норма |
| `0.60 < HI <= 0.85` | Удовлетворительно |
| `0.35 < HI <= 0.60` | Требует контроля |
| `HI <= 0.35` | Аварийное |

Таблица скоростных порогов:

| Скорость | Порог виброускорения |
|---|---|
| `< 40 км/ч` | `2.1 g` |
| `40-80 км/ч` | `3.0 g` |
| `> 80 км/ч` | `3.9 g` |

Кодовая опора:

- `src/utils/health_index.py`;
- `src/utils/thresholds.py`.
